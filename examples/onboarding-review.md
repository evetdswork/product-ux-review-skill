# Example UX Review

Input:
"Review this fintech onboarding screen"

Output:

# UX Review

## Summary

The onboarding flow is visually clean but introduces cognitive overload during account setup.

## Critical Issues

* Too many required fields on first screen
* Primary CTA lacks contrast

## Medium Issues

* No progress indicator
* Error states are unclear

## Minor Issues

* Secondary buttons visually compete with main CTA

## Recommendations

* Split onboarding into multiple steps
* Improve CTA hierarchy
* Add inline validation

## Product Thinking Notes

The current onboarding may reduce conversion due to high initial friction.
